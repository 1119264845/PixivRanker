# Pixiv 排行榜下载器

一个面向 Windows 的 Pixiv 排行榜归档工具。它使用 WebView2 完成 Pixiv 登录并复用会话，然后读取排行榜内容、展示作品信息，并按名次批量下载原图或动图原始 ZIP。

项目定位为个人本地归档工具，强调简单、直观和可重复下载：再次下载同一榜单时，会根据作品 ID 自动跳过已经完整保存的作品。

## 技术栈

- .NET 8
- WPF + XAML
- C#
- Microsoft WebView2
- `HttpClient` + Pixiv AJAX 接口
- `System.Text.Json`

## 第一版功能

- WebView2 内嵌 Pixiv 官方登录页，并复用独立浏览器配置中的登录状态。
- 排行内容：综合、插画、动图。
- 全年龄排行：今日、本周、本月、新人、原创、AI 生成、男性欢迎。
- R-18 排行：今日、本周、AI 生成、男性欢迎。
- 自动隐藏 Pixiv 不支持的内容/排行组合。
- 获取排行榜前 100 名。
- 下载名次支持单项（`5`）或区间（`6-10`），范围限制为 1–100。
- 榜单目录下直接保存图片，不再为每个作品创建子目录；多页作品以 `_P0`、`_P1` 区分。
- 动图下载原始 ZIP，并保留还原动画所需的帧延时信息。
- 再次下载同一榜单时，会按作品 ID 自动跳过已完整下载的作品（也兼容第一版的作品子目录）。
- 自动记住上次选择或输入的保存目录。
- 支持浅色、深色两套主题，并记住上次使用的主题。

## 构建

需要 Windows、.NET 8 SDK 和 WebView2 Runtime：

```powershell
dotnet restore .\PixivRanker.sln
dotnet build .\PixivRanker.sln -c Release
```

输出位于 `src\PixivRanker\bin\Release\net8.0-windows\`。

## 使用方式

1. 启动程序并在内置 Pixiv 页面中登录。
2. 选择排行榜类型、日期范围和作品类型。
3. 获取排行榜后选择要下载的名次或名次区间。
4. 选择保存目录并开始下载。

程序会记住上次使用的保存目录和主题设置。
